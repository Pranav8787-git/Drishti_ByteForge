# Drishti: A campus that sees, decides and acts
Team ByteForge · Agra College Hackathon 2026

Live room occupancy that saves power, frees up space and keeps
attendance accurate and honest. Only counts people. No faces stored.

## How it works
1. **See:** YOLOv8 + OpenCV count people from a CCTV, webcam or old phone
2. **Decide:** Python + FastAPI rules check the timetable, empty time and attendance sheet
3. **Act:** Telegram alert at 10 min empty, power cut at 15 min unless admin replies OFF

## Folders
- `vision/` people counting
- `backend/` API, rules engine, database
- `dashboard/` live floor plan
- `data/` rooms, timetable and mock data
- `docs/` idea submission deck
